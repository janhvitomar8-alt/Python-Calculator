# Python Calculator

A simple command-line calculator built using Python. This project performs basic arithmetic operations and demonstrates the use of functions, loops, conditional statements, and user input handling.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Menu-driven interface
* Continuous calculations until exit

## Concepts Used

* Python Functions
* Parameters and Return Values
* Loops (`while`)
* Conditional Statements (`if`, `elif`, `else`)
* User Input
* Basic Arithmetic Operations

## How to Run

1. Install Python.
2. Open a terminal in the project folder.
3. Run:

```bash
python calculator.py
```

## Example

```text
1. Add
2. Subtract
3. Multiply
4. Divide
5. Exit

Enter choice: 1
Enter first number: 10
Enter second number: 5

Answer = 15
```
